# Finalization Checklist

Use this when sending the next batch of text, images, and videos.

## Project Evidence

For each project, aim for:

- One strong thumbnail or first image.
- One architecture/system image.
- One result plot, table, waveform, or screenshot.
- One short video or GIF if motion matters.
- Two or three captions that explain what the viewer is seeing.
- A short "what changed after this project" note if the learning is not obvious from the artifact.

## Text Pass

Good project text should answer:

- What was the project trying to prove or build?
- What did I actually build, test, or debug?
- What evidence shows that it worked?
- What did I learn that changed how I approach the next project?
- What is intentionally private, unpublished, or still unfinished?
