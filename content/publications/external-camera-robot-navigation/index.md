abstract: |
  This in-progress MSc graduation project investigates mobile robot navigation using observations from an external fixed camera. The work combines camera projection geometry, homography-based localization, robot state estimation, and learning-based planning/control to study how externally observed sensing can support autonomous navigation.

  The project focuses on the practical limits of external perception: camera viewpoint, visibility, calibration, and sensor reliability. Simulation experiments are used to compare navigation behavior under controlled variations in perception quality and environment setup.

## Focus

- External-camera robot localization using projective geometry and planar homography.
- Navigation behavior under changing visibility and sensor reliability.
- Simulation-based evaluation with a path toward real-world robotic constraints.
